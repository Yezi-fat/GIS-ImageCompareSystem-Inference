## 三、本期排坑记录

1. **GPU 镜像 ubuntu22.04 基础镜像**：默认 python3=3.10（不满足 >=3.11）且 Debian 禁用 ensurepip——以 `python3.11 -m venv /opt/venv` 引导 pip（python3.11-venv 提供捆绑 wheel）；
2. **onnxruntime 与 onnxruntime-gpu 同 namespace 互斥**：GPU 镜像先装主依赖再卸载 CPU 版换装 GPU 版；
3. **docker.io 直连超时**：nvidia/cuda 基础镜像经 docker.m.daocloud.io 拉取后本地 tag；
4. **WSL2 宿主机供图**：容器经 host.docker.internal 访问 WSL 内服务不通（Docker Desktop 拓扑），容器间供图（同网络 imgsrv）为正确验证拓扑。
