## 三、关键技术决策与偏差记录

1. **instructor 未采用**（设计偏差，已记 V2.6 修订⑦）：instructor 依赖 OpenAI SDK 客户端对象，与"httpx 直调完整 URL、不经 SDK 路径拼接"（约束 #10）不兼容；结构化输出以 `response_format=json_object` + Pydantic 校验重试 2 次实现同等约束。
2. **地理编码失败回退地名词典**（设计 V2.6 注记）：词典命中则低置信返回 bbox 并标注 uncertain_fields（FR-9.6 离线定位能力），词典未命中才 location=null（FR-9.8）。
3. **名词候选剔除行政区词**：词典成员（"四川"⊂"四川省"）与"省/市/区/街道"类后缀词不进入要素候选——冒烟实测曾产生 unsupported 噪声（"四川/成都/街道"），已修并加回归断言。
4. **规则解析 confidence 恒 0.5**：能力受限明示（FR-9.6），<0.7 触发 uncertain_fields 标注与强制确认高亮（FR-9.4）。
5. **熔断器为进程级单例**：参数经 L1 配置注入；测试经替换 `parser._circuit` 实例重置（clock 可注入）。
