# 配置项说明（Python 推理计算服务群）

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-10-02 |
| 对应事项 | docs/bug/bug-2026-09-28.md 咨询 Q1（配置项含义与生效方式） |
| 事实源 | 三服务 `src/*/config.py` 的 pydantic Field description（改配置先改代码注释，本表随版本同步） |

**通用机制**：

- 配置体系为 pydantic-settings，环境变量注入，嵌套分隔符 `__`（如 `REMOTE__ENDPOINT` → `remote.endpoint`）；
- 全部配置为 **L1 部署配置**：改后须重启容器生效（`docker compose up -d --force-recreate`）；
  业务策略参数（阈值/配色/类别映射/min_area 等）不在此处——由 Java 运行配置持有、逐请求下发（FR-10）；
- URL 类配置项一律为**完整 URL**（含路径，代码不拼接），启动即校验，非法拒绝启动；
- 部署范例：`deploy/.env.example`（逐项行内注释，与本表同源）。

## 三服务公共

| 环境变量 | 默认值 | 含义与生效方式 |
| --- | --- | --- |
| `AUTH_ENABLED` | `true` | 内部令牌鉴权总开关（FR-10.7）。与 Java 侧 `security.auth.enabled` 同一环境变量注入，两侧须同值；`/health` 恒豁免 |
| `INTERNAL_TOKEN` | 空 | 内部共享密钥（`X-Internal-Token` 校验值），**必须取 Java 侧现值**，自行生成会导致 Java→Python 401（历史排坑） |

## infer-service（:8001）

| 环境变量 | 默认值 | 含义与生效方式 |
| --- | --- | --- |
| `SERVICE__PORT` | `8001` | 服务监听端口 |
| `SERVICE__DEFAULT_PROVIDER` | `local-cpu` | `X-Inference-Provider` 提示头缺省时的兜底提供方（`remote`/`local-gpu`/`local-cpu`，**仅小写连字符**，非法值启动即拒）。注意：Java 正常路径必带提示头，本配置仅兜底；端到端切换走 Java 运行配置（部署文档 §9.1） |
| `MODELS__DIR` | `/models` | 模型文件挂载点，按 `{name}/{version}/{fp32,int8}.onnx` 组织；须与 compose volume 挂载目标一致 |
| `MODELS__SEGMENTATION__NAME` / `VERSION` | `landcover-seg` / `v2.0` | 默认分割模型名与版本（请求未带 model_name/model_version 时使用；Java 激活版本随请求下发，优先级更高） |
| `MODELS__SEGMENTATION__CLASS_IDS` | 空（自动推导） | 分割模型输出类别 ID 表，与 Java element_catalog 的 `model_class_id` 对齐（FR-6.2）。**缺省时从模型 ONNX 元数据 names 自动推导**（检测模型类别序号直用、末位通道为背景）；显式配置则以配置为准并做通道错配校验（V1.1） |
| `MODELS__SEGMENTATION__FP32` / `INT8` | `fp32.onnx` / `int8.onnx` | 双产物文件名约定（FP32=GPU 路径，INT8=CPU 路径） |
| `MODELS__SEGMENTATION__CONF_THRESHOLD` | `0.25` | 检测置信度过滤阈值（仅 YOLO 系检测输出格式生效） |
| `MODELS__SEGMENTATION__NMS_THRESHOLD` | `0.45` | 逐类 NMS IoU 阈值（仅 YOLO 系检测输出格式生效） |
| `MODELS__CHANGE_DETECTION__NAME` / `VERSION` | `change-detection` / `v1.2` | 默认变化检测模型名与版本（机制同分割） |
| `MODELS__CHANGE_DETECTION__FP32` / `INT8` | `fp32.onnx` / `int8.onnx` | 同上 |
| `TILING__TILE_SIZE` | `256` | Tile 边长（像素），大图按此流式切块推理 |
| `TILING__OVERLAP` | `32` | 切块重叠像素（stride=224），重叠区均值融合保证无接缝（FR-6.7） |
| `CONCURRENCY__CPU_SLOTS` | `2` | CPU 推理信号量槽位数（超并发排队防内存打爆）；`intra_op_num_threads = CPU 核数 / 槽数` |
| `CONCURRENCY__GPU_SLOTS` | `4` | GPU 推理信号量槽位数 |
| `REMOTE__ENDPOINT` | 空 | 远程推理平台完整端点 URL（直调不拼接）；空=未配置远程（正常形态） |
| `REMOTE__TIMEOUT_S` | `25` | 远程单次调用超时（秒），略小于 Java 侧 30s，保证错误先在本层成形 |
| `REMOTE__BATCH_SIZE` | `8` | Tile 批量推理分组大小（FR-1.9），批量失败自动逐块重试一次 |
| `LIMITS__LOCAL_CPU_MAX_INPUT` | `2048` | local-cpu 模式输入边长上限（像素），超限返 INPUT_TOO_LARGE（R-04 兜底，Java 拦截为主） |
| `STORAGE_READER__TIMEOUT_S` | `30` | 预签名 URL 拉图超时（秒） |
| `ALIGNMENT__MAX_SHIFT_PX` | `4` | 配准校验整体平移阈值（像素），超限返 ALIGNMENT_FAILED（§3.2.5 告警路径） |

## nlp-service（:8003）

| 环境变量 | 默认值 | 含义与生效方式 |
| --- | --- | --- |
| `SERVICE__PORT` / `SERVICE__LOG_LEVEL` | `8003` / `INFO` | 端口与日志级别 |
| `NLP__LLM_URL` | 空 | 内网 LLM 完整 chat completions 端点（OpenAI 兼容协议，httpx 直调）；空 = LLM 不可用 → 常驻规则解析降级（`nlu_provider=rule-based`，FR-9.6/9.7） |
| `NLP__LLM_MODEL` | `qwen2.5-14b-instruct` | LLM 模型名（请求体 model 字段） |
| `NLP__LLM_TIMEOUT_S` | `15` | 单次 LLM 调用超时（秒），超时即当次降级规则解析（FR-9.7） |
| `NLP__CIRCUIT__FAILURE_THRESHOLD` | `5` | 熔断器：窗口内连续失败次数触发断流 |
| `NLP__CIRCUIT__WINDOW_S` | `60` | 熔断失败计数窗口（秒） |
| `NLP__CIRCUIT__OPEN_DURATION_S` | `30` | 断流时长（秒），之后半开试探，成功闭合 |
| `NLP__GEOCODER_PROVIDER` | `nominatim` | 地理编码提供方：`amap` / `baidu` / `nominatim`（公网可达用高德/百度，内网离线自部署 Nominatim） |
| `NLP__GEOCODER_URL` | 空 | 地理编码完整端点 URL（仅按 provider 协议拼 query 参数）；空 = 不可用 → 回退内置地名词典（FR-9.8 部分成功降级） |
| `NLP__GEOCODER_KEY` | 空 | 高德/百度服务密钥（nominatim 不需要） |
