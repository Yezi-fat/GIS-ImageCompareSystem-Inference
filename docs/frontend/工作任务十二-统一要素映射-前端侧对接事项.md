## F-0 零代码结论

要素选择器数据源为 Java `GET /api/v1/elements`（目录驱动渲染），Java 将目录切换为
统一 9 要素（水体/森林/草地/淹水植被/耕地/灌丛/建筑/裸地/冰雪覆盖）后，前端自动生效：

- "雪山覆盖"更名为**冰雪覆盖**并恢复可选（低层级链路可识别，Dynamic World 含 snow_and_ice）；
- 新增要素：水体、淹水植被、耕地、灌丛、裸地。

## F-1【建议】按地图层级禁用不支持要素（体验增强）

两套模型能力不同：YOLO（z>12 高层级）不支持冰雪覆盖/淹水植被/灌丛/裸地 4 类。
当前不支持的要素在该层级提交会返回 400（UNSUPPORTED_ELEMENT，Java 透传）。

建议（需 Java 配合提供支持矩阵，见 Java 侧对接文档 E-3）：
- 前端按当前地图层级动态置灰不支持的要素项，tooltip 说明
  「该要素仅支持 ≤12 级低层级分析」；
- 若 Java 未提供矩阵，退化为错误提示文案优化：识别到 UNSUPPORTED_ELEMENT 时提示
  「所选要素在当前地图层级不支持」。
